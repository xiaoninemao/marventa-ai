# Marketing copy edit

When the user asks to revise existing work, apply the requested change to the selected draft or section while preserving the original message, requested language, and format. Review the revised text for:

- Clarity: the reader can identify the main point without decoding jargon or long sentences.
- Relevance: product details answer a real reader need rather than merely naming features.
- Voice: wording fits the supplied brand tone and the rest of the content.
- Evidence: claims, numbers, comparisons, and testimonials are supported; remove unsupported additions.
- Action: any invitation to respond or act is natural and feasible for the selected platform.
- Economy: trim repeated claims and generic praise without removing useful detail.

For visual directions, apply the same checks to cover text and design recommendations. Keep the host application's output fields and the user's specific edit request authoritative.
