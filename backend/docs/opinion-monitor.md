# 账号舆情监测

「舆论追踪」与发布管理、账号内容、线索追踪并列位于运营导航中，线索追踪保留评论洞察、意向评估与每日简报。页面按项目、账号和近 7／30 天筛选，从所选账号各作品的每日评论快照读取数据，不另外抓取平台评论。统计口径是已采集且按评论 ID 去重的评论；缺失快照的日期不会算作零评论，采集不完整日期会单独计数。仅组织和项目授权用户可读取对应账号，模拟快照只在现有本地预览防护条件下可见。

页面展示关键监测指标（推广内容、累计曝光、内容互动、正向评论占比、待处置风险）、推广表现趋势、情感结构、关注话题的评论数与关键词进度条、推广内容表现，以及用户声音与行动建议。待处置风险按当前周期内尚未复核的负向评论计数。情感是与产品体验有关的保守规则识别，拒绝某项功能不直接视作负面情绪，讽刺和冲突表达进入待复核。主题占比基于全部已采集评论，互动量不作为统计权重。推广表格只显示授权账号作品已同步的曝光、点赞、回复与分享数据；缺失的指标显示空值，不用评论互动量推算作品指标。评论列表读取每日简报中各作品的全部评论并按评论 ID 去重，支持情感筛选、搜索和查看证据。内容和评论抽屉沿用交互原型的查看与复制操作；评论线索的确认标记只在当前页面生效。

作品指标来自授权平台提供的累计统计。同步时按账号、作品和本地日期保存一份快照；趋势图显示连续两天快照之间的曝光和互动增量，前期对比取上一等长周期的实际快照。缺少快照或平台未提供该字段时留空，不推算历史曲线。已有作品的首次同步只能形成累计卡片值，待第二次按日同步后才有可计算的日增量。

## 主题模型

主题仅采用 BERTopic 和本地句向量模型，不调用外部 LLM。安装可选依赖：

```powershell
cd backend
.venv\Scripts\python.exe -m pip install -r requirements-opinion.txt
```

下载并保存一个支持中文的 SentenceTransformers 模型，然后设置 `LEAD_OPINION_EMBEDDING_MODEL_PATH` 为其**本地目录**，例如 `paraphrase-multilingual-MiniLM-L12-v2` 的本地快照。服务不会在分析请求时自动下载模型。主题固定为采购与试用、报表与数据、系统对接、企业配置、使用体验、上手服务六类；模型无法可靠归入这六类的评论计入「其他」。每次以最近 30 天的语料建立主题映射，再分别统计 7／30 天；新快照出现时缓存失效。30 天内少于 30 条不同评论文本、未配置模型或模型运行失败时，其余概览仍可用，主题区域显示对应空状态。

主题关键词在句向量提取后进行中文分词、停用词和高频词处理，保留原句的否定表达；同义词用于合并展示词。页面按原型样式展示各话题评论数、相对最多评论话题的进度条和关联关键词，并支持复制当前话题摘要。模型名、分词与停用词说明不会显示在前端。

## AI 策略建议

策略依据取所选周期内已存的每日简报和人工议题决策：未决策的主题为「待确认需求」，已采纳但未完成的主题为「待推进优化」。完成记录保存在 `lead_opinion_action_progress`；被忽略或已完成的主题不进入策略输入。页面右侧卡片在未主动调用模型时展示简报中已经保存的建议；主动生成成功后替换为模型建议，并显示来源日期。负面反馈和待复核数从已存简报汇总，不会凭少量评论虚构风险事件。

`LEAD_OPINION_STRATEGY_LLM_ENABLED=false` 默认关闭。需要使用时将其设为 `true`，并配置现有统一 AI 提供方的 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`，或启用线索追踪专用提供方配置。点击「生成 AI 策略建议」才会调用模型。输入只包含所选账号和周期内未完成／未确认的议题、简报摘要、脱敏证据和已存决策；输出必须是结构化 JSON，引用有效事项 ID，校验失败返回错误，不保存或执行建议。页面会标明来源日期，建议仍由团队人工决策。

接口基路径：`/api/v1/publishing/projects/{project_id}/channel-accounts/{account_id}/lead-tracking`。

- `GET /opinion-overview?days=7|30`：聚合图表与主题。
- `GET /opinion-actions?days=7|30`：待办和模型可用状态。
- `GET /opinion-details?days=7|30`：作品推广指标和关联评论。
- `POST /opinion-actions/accept?days=7|30`：把待确认议题纳入优化，JSON 为 `{"action_id":"..."}`。
- `PATCH /opinion-actions?days=7|30`：已采纳事项完成／恢复，JSON 为 `{"action_id":"...","completed":true|false}`。
- `POST /opinion-strategy?days=7|30`：按当前待办调用可选模型。

舆情页顶部的推广表现、评论舆情与策略建议用于定位页面区块，不会隐藏其他区块。
